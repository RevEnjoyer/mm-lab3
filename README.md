# ЛР 2.2 — Реализация многопоточной архитектуры

Дисциплина: «Проектирование и программирование мультимедийных приложений».
**Вариант 1** (номер в журнале 20: `20 % 5 + 1 = 1`) — асинхронная загрузка файла.

| Параметр | Значение |
| --- | --- |
| Элемент запуска | кнопка «Загрузить файл» |
| Фоновая операция | чтение выбранного файла порциями по 64 КБ |
| Индикация | QProgressBar (0–100%) |
| Результат | сообщение об успехе (имя + размер) или об ошибке |

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `worker_thread.py` | класс `WorkerThread(QThread)` — фоновое чтение файла |
| `main.py` | главное окно, диалог выбора файла, обработчики сигналов |
| `requirements.txt` | зависимости Python |
| `.gitignore` | исключения для Git |
| `INSTRUCTIONS.md` | пошаговая инструкция по выполнению |

## Требования

- Python 3.8+
- PyQt6 6.4+

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Обрабатываемые ошибки

- файл не найден (в т.ч. удалён между выбором и началом чтения);
- нет прав на чтение файла;
- прочая ошибка файловой системы во время чтения;
- отмена выбора файла в диалоговом окне.
